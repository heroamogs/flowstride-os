# Security Policy

## Reporting a Vulnerability

We take the security of Flowstride OS and our users very seriously.

If you discover a security vulnerability, we kindly ask that you **do not** report it by opening a public GitHub Issue. Instead, please practice responsible disclosure by contacting us privately.

**Please report security issues via email to:** security@flowstride.io

### What to include in your report

To help us resolve the issue as quickly as possible, please include the following in your email:

- A description of the vulnerability and its potential impact.
- The steps required to reproduce the issue.
- The version of Flowstride OS and Node.js you are using.
- Any relevant logs, screenshots, or code snippets.

### Our Response Process

1. We will acknowledge receipt of your vulnerability report within 48 hours.
2. We will investigate the issue and determine the severity and timeline for a patch.
3. We will keep you updated on our progress and notify you once the patch is released.
4. Once the issue is resolved, we will publish a security advisory and publicly acknowledge your contribution (if you wish to be credited).
